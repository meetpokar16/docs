Themes change the appearance of Rivlo. Your selected theme can also affect supported Home Screen widgets.

![Rivlo Home screen shown in multiple theme color accents](https://rivlo.3bytes.org/guide-assets/premium-themes.png)

## Available themes

Rivlo includes built-in themes such as:

| Theme | Description |
| --- | --- |
| Rivlo Blue | Default theme |
| Dark | Dark theme |
| Monochrome | Black and white |
| Gold | Warm theme |
| Sunfire | Brighter, more colorful theme |

Additional themes may be available with **Rivlo Pro**.

## How to change your theme

1. Open **Account** in Rivlo.
2. Open **Themes**.
3. Select a theme.

You can also reach theme settings from the Account screen list shown in [Account and settings](/account-settings/overview).
