Rivlo widgets let you see selected Rivlo information on your iPhone Home Screen without opening the app.

Widgets update during the day as your Rivlo data changes.

## Available widgets

| Widget | What it shows |
| --- | --- |
| **Daily Activity** | Current step count and progress toward your daily goal |
| **League Status** | Current League and ranking |
| **League Progress** | Progress toward the next League tier |
| **Activity Heatmap** | Activity over the past 30 days |
| **Shadow** | A minimal activity widget with less detail |

## Widget sizes

Rivlo widgets are available in different sizes. When you add a widget, iOS shows the sizes available for that widget. The information shown can vary by widget and size.

## Add a Rivlo widget

1. Touch and hold an empty area of the Home Screen until the apps start to jiggle.
2. Tap the **\+** button.
3. Search for **Rivlo** and select it.
4. Browse the available widgets and choose one.
5. Select the widget size.
6. Tap **Add Widget**.
7. Move the widget to the position you want.
8. Tap **Done**.

## Change a widget

1. Touch and hold the Rivlo widget.
2. Tap **Edit Widget** if available.
3. Change the available settings.
4. Close the widget settings.

Available options depend on the widget.

## Themes

Rivlo themes change the appearance of the app and supported widgets.

| Theme | Description |
| --- | --- |
| Rivlo Blue | Default theme |
| Dark | Dark theme |
| Monochrome | Black and white |
| Gold | Warm theme |
| Sunfire | Brighter, more colorful theme |

Open **Settings** in Rivlo and find **Appearance** or **Theme** to change themes. Additional themes may be available with Rivlo Pro.

## Widget data and troubleshooting

Widgets display information from Rivlo. If a widget is not showing the latest information, open Rivlo and check whether your activity has updated there first. Widget updates can also depend on iOS widget update behavior.

If Rivlo does not appear in the widget picker:

1. Make sure Rivlo is installed.
2. Open Rivlo once.
3. Open the widget picker again and search for **Rivlo**.

If steps still look wrong, see [Why aren't my steps updating?](/troubleshooting/steps-not-updating).
